# borb-amq

Self-hosted anime music quiz with a buzzer gamemode: the music plays for
everyone, the first buzz pauses it and takes the floor, and a wrong answer
locks you out and resumes the music for everyone else.

Catalog and audio come from [AnimeThemes](https://animethemes.moe). Keep it
non-commercial (their ToS), and set `INGEST_USER_AGENT` in `.env` to a real
contact before ingesting.

```bash
npm install
cp .env.example .env
npm run ingest                # full catalog, ~6 min
npm run dev                   # server on :8080, client on :5173
npm run build && npm start    # production
```

Install ffmpeg if you host this anywhere public. The host can narrow the song
pool to the players' MyAnimeList lists from the lobby.
